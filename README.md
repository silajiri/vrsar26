# vrsar26: Istrie 27. 10. – 1. 11. 2026

Statická stránka s itinerářem rodinného výletu do Vrsaru (Maistra Resort Belvedere): trasa autem, ubytování, atrakce pro malé děti, víno, olivy, lanýže a rozpočet.

- `index.html`: struktura a statické sekce
- `data.js`: místa, itinerář a rozpočet (**ceny a časy se upravují tady**)
- `app.js`, `style.css`: vykreslení, mapa (Leaflet), rozpočet, vzhled

Publikace: Settings → Pages → Deploy from branch `main` / root.
